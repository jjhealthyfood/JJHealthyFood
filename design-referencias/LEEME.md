# Referencias de diseño

Deja aquí los archivos de referencia (HTML, PDF, imágenes, fuentes).

## Qué ayuda más (en orden)

1. **HTML** de cada pantalla — es lo ideal: puedo leer colores, tipografías,
   espaciados y componentes exactos.
2. **PDF** — sirve para ver la composición y el estilo, pero tengo que interpretar medidas.
3. **Capturas PNG/JPG** — útiles como apoyo, no como única referencia.
4. **Assets** — logo nuevo (SVG o PNG grande), fotos, iconos y fuentes.

## Estructura sugerida

```
design-referencias/
├─ landing.html          (o .pdf)
├─ wizard-pedido.html
├─ panel-admin.html
├─ login.html
└─ assets/
   ├─ logo.svg
   └─ fotos/
```

Si el HTML usa una carpeta de assets (css/, images/, fonts/), cópiala completa
para que las rutas sigan funcionando.

## Importante

La referencia se usa para el **diseño** (layout, colores, tipografía, componentes).
El **contenido real** se conserva: menú, comidas, precios, extras, sedes,
categorías y datos de la base de datos no se inventan ni se reemplazan.
